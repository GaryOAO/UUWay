## Compatibility

The streaming imports retain the bridge's DXGI, D3D11, USER32 input, cursor
and display boundaries. The Microsoft ConPTY DLL is byte-identical to 4.42;
the updated terminal bridge still works with the existing UUWay shim and
PowerShell proxy. No native binary or vendor offset changes were required.

The installed 4.46 server reached `native_input_hook_ready`, the environment
doctor passed without warnings, and the controller user confirmed connection
and common features, including the prompted screen, input and terminal checks.
This does not establish compatibility on other GPUs or desktop environments.

## In-app upgrade lifecycle

UU stages 4.46 in a version directory, then its `/mode=5` installer commit
renames `bin` to `4.42.0.2770` before installing the new `bin`. Previously,
UUWay treated its missing loader links as unexpected replacements and killed
the owned Wine prefix during cleanup, interrupting that same installer.

The new supervisor recognizes only a real numeric version directory holding
the original loader-link inodes and targets, with the other runtime links
unchanged. It waits up to 180 seconds for the prefix's updater processes to
exit and the complete payload to remain stable for two seconds. Watchdog and
startup-timeout notifications continue during the wait. Other replacements
still stop the worker. An explicit stop cancels the wait.

Cleanup removes only owned links, including those moved into the old version
directory. The supervisor then restores an absent terminal proxy, reattaches
the native runtime and starts the new vendor server. Existing user/vendor
files are preserved.

Regression validation restored the original 4.42 prefix from a private backup
and replayed the official staged 4.46 `/mode=5` commit. The installer exited
zero; the worker waited until completion, removed all six owned loader links
without cleanup failures and restarted into 4.46 without a systemd service
restart. The terminal bridge became ready again. Tests also cover copied
backups, symlinked directories, cancellation, timeout and replacement files.

For an installation already left without `bin` by the previous behavior, stop
the bridge, rerun the official installer with the existing Wine prefix, then
start the bridge. Preserve a prefix backup first; login information remains in
the existing prefix.
